description: 查看 WorkBuddy / CodeBuddy 当前登录账号、认证文件位置与客户端运行状态
argument-hint: "[cn|ai]"
---

查询本机当前的 WorkBuddy 登录态。

调用 MCP 工具 `wb_status`，参数：

- 若用户指定了档位（国内版 / 国际版，或 `cn` / `ai`），传入对应的 `variant`；
- 未指定则不传，默认国内版。

拿到结果后，用中文简要汇报：

1. **当前账号**：优先显示昵称，其次邮箱；都没有则显示「未登录」。
2. **客户端运行状态**：`running` 为真时说「WorkBuddy 运行中」，否则说「未运行」。
3. **档位**：说明是国内版还是国际版。
4. 顺带给出认证文件路径，便于用户排查。

不要输出原始 JSON，也不要解释工具调用过程。若工具报错，直接说明失败原因即可。
